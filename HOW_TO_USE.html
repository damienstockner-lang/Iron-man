🤖 FRIDAY ASSISTANT - HOW TO USE

Step-by-step visual guide for beginners

📋 Prerequisites:
• Python 3.8 or later installed
• Terminal/Command Prompt access
• The Friday Assistant files downloaded

Step 1: Open Your Terminal

On Windows:
Press Win + R, type cmd, press Enter

On Mac:
Press Cmd + Space, type Terminal, press Enter

On Linux:
Press Ctrl + Alt + T

Step 5: Try Your First Command - Add a Task

Terminal
$ python3 -m friday_assistant task --add "Buy groceries" --priority high Task added: Buy groceries [high]

Step 6: List Your Tasks

Terminal
$ python3 -m friday_assistant task --list [1] Buy groceries (pending) [high]

Step 7: Record Your Steps

Terminal
$ python3 -m friday_assistant steps --count 5000 Recorded 5000 steps $ python3 -m friday_assistant stats Friday Stats Tasks: 1 total, 0 completed Notes: 0 Events: 0 Contacts: 0 Total Steps: 5000 Total Expenses: $0.00

Step 8: Add a Habit and Track It

Terminal
$ python3 -m friday_assistant habit --add "Exercise" Habit added: Exercise [1] $ python3 -m friday_assistant habit --complete 1 Habit 1 completed $ python3 -m friday_assistant habit --list [1] Exercise (daily) streak=1 best=1

Step 9: Start a Pomodoro Timer

Terminal
$ python3 -m friday_assistant pomodoro --start "Write code" Pomodoro started: Write code [1] $ python3 -m friday_assistant pomodoro --list [1] Write code 2026-08-29T04:22:31.415544 -> running

Step 10: Try Voice Control (If Microphone Available)

Terminal
$ python3 -m friday_assistant tv --device LivingRoom --listen [Listen] Listening for 'LivingRoom'... [Listen] Heard: turn on the TV Voice command: turn on the TV -> sent 'on' to LivingRoom

Quick Reference
# Tasks python3 -m friday_assistant task --add "Task name" --priority high python3 -m friday_assistant task --list python3 -m friday_assistant task --done 1 # Steps & Stats python3 -m friday_assistant steps --count 5000 python3 -m friday_assistant stats # Habits python3 -m friday_assistant habit --add "Exercise" python3 -m friday_assistant habit --complete 1 python3 -m friday_assistant habit --list # Shopping python3 -m friday_assistant shopping --add "Milk" python3 -m friday_assistant shopping --list # Pomodoro python3 -m friday_assistant pomodoro --start "Coding" python3 -m friday_assistant pomodoro --list # Today's Schedule python3 -m friday_assistant today # Open Websites python3 -m friday_assistant open google python3 -m friday_assistant open youtube # Backup & Restore python3 -m friday_assistant backup python3 -m friday_assistant restore
⚠️ Important Notes:
• Replace python3 with python on Windows if needed
• Always run commands from the project folder
• Some features need internet or extra hardware (microphone, IR blaster)
• Use --help after any command to see options
